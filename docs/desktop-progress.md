# 桌面版长期任务进度

本文件是桌面版移植的**唯一进度来源**。每次新会话先读本文件与 `docs/desktop-plan.md`,再说「继续」即可接着做,不依赖对话记忆。完成一项就勾选、记下验证结果。

## 协作分工

- **我(agent)**:写代码、单测、构建脚本、验证脚本、文档;更新本文件;把大任务拆成可独立验收的小步。
- **你**:在 macOS / Windows 实机上按下方清单手动验证,回传现象、日志、截图;阶段 4 提供 Apple Developer 账号与代码签名证书。
- **安装包获取**:push 到 `desktop` 分支后,`.github/workflows/desktop-build.yml` 自动构建;在 Actions 运行页的 **Artifacts** 里下载 `selected-text-translator-macOS` / `selected-text-translator-Windows`。macOS 有 x64 与 arm64 两个 dmg,按机器架构选(x64 的文件名不带 `-x64` 后缀)。
- **凭据**:API Key、证书、账号一律走环境变量或仓库外私有配置;不要发给我,不要出现在截图、日志、测试报告、提交里(沿用 AGENTS.md 约定)。

## 环境约束(固定事实,不要反复确认)

- 本地环境:Ubuntu / Node 22.22.1 / npm 9.2.0,npm registry 可访问;已装 Xvfb,可无头启动 Electron 应用做启动验证。
- **没有 macOS / Windows 环境可提供**,但 CI 用 GitHub 托管的 `macos-latest` / `windows-latest` runner 产出安装包,已跑通。
- 用户无法方便提供目标平台环境,**实机交互测试全部由用户手动执行**,我按回传迭代。
- 我没有 GUI 交互能力:看不到窗口、点不了系统授权弹窗、没法在应用里选中文字按快捷键。凡涉及交互的验证都必须由你执行。
- 用户提供的真实 API 凭据仅用于本地一次性端到端验证,放在仓库外 `/tmp/opencode/`,不进仓库、提交、日志或截图,用完删除。

## 用户反馈(驱动 v0.8.1 起的重新设计)

> Windows 上按 `Alt+Shift+E` 没反应;"让你移植也不是让你全盘照搬,要按客户端软件的使用逻辑做对应修改或优化";希望有类似 ChatGPT 的对话框,没法选区的内容可以自己复制过来翻译。

原来的实现把浏览器扩展的「注入浮层 + DOM 选区」整套搬过来:取词失败或剪贴板为空时直接 `hide()`,用户看不到任何反馈。已按桌面软件逻辑重做,见下方里程碑与 v0.8.1–v0.8.10 变更记录。

## 手动实机验证清单(由你执行)

回传时请附:平台 + 系统版本 + 代码版本(commit)、操作步骤、预期 vs 实际、日志、截图。截图注意避开 API Key 输入框。

### 清单 1 — 主交互(两平台通用)
1. 从 GitHub Releases(推 `desktop-v*` 标签自动发布,含版本说明)或 Actions 的 Artifacts 下载安装包。**macOS 选对架构**:Intel 用 `Selected Text Translator-<版本>.dmg`,Apple Silicon 用 `...-arm64.dmg`。当前产物未签名,macOS 首次打开需在「系统设置 → 隐私与安全性」允许,Windows 可能出现 SmartScreen 提示。
2. 启动 App,托盘/菜单栏图标出现,不弹主窗口(启动已预加载,热键响应更快)。
3. 首次启动应自动展开内嵌设置面板;填入 API 地址、API Key、翻译模型,点「检测连接」应能拉到模型列表,保存后面板收起。
4. **关键回归**:在记事本/浏览器里选中一段英文,按 `Alt+Shift+E`。预期:**鼠标附近弹出悬浮翻译卡片**(主窗口不弹出),卡片流式显示译文;点其他窗口或 `Esc` 卡片关闭,主窗口消息流里出现这条记录。
5. **关键回归**:不做任何选中、剪贴板为空时按热键。预期:窗口仍然弹出,输入框聚焦,提示"可以直接粘贴到这里翻译"——不应再出现"没反应"。
6. **新功能**:复制一段无法选区的文字(或随便一段文本),直接粘贴到输入框;默认应自动翻译(可在输入框下方关掉「粘贴后自动翻译」)。
7. Windows 若模拟 `Ctrl+C` 取词失败:设置里勾选「仅用剪贴板取词」,先复制再按热键,应能翻译。
8. 设置里把快捷键改成自定义组合(如 `Ctrl+Alt+T`),用新组合触发;改回或换一个冲突组合,确认失败有状态栏提示。
9. 回传:卡片是否弹出、取词来源显示、译文是否正常、日志有无报错(托盘「打开日志」)。

### 清单 2 — 功能与数据
1. 朗读原文/停止;试听音色、语速。
2. 收藏一条 → 打开表达本 → 退出并重启 App → 数据仍在 → 导出 JSON → 清空后导入 → 条数与复习进度一致。
3. 重启 App 后历史对话仍在;点原文气泡可回填输入框。
4. 设置项、主题、字号、窗口位置尺寸、置顶、开机自启重启后保持。
5. API Key 在 `userData/sync.json` 中应为 `enc:v1:` 开头的密文而非明文。
6. 回传:音色列表是否为空、有无 TTS 报错、数据是否持久。

### 清单 3 — 阶段 3(最关键)
**macOS**
1. 首次启动是否弹出辅助功能授权;授权后重启 App。
2. 分别在 Safari、Word、VS Code、预览(PDF)中选中文字并按热键,确认是否取到(不依赖剪贴板)。
3. 卡片是否贴着选区位置(rect)。
4. 全屏应用、多 Spaces / 外接显示器下窗口是否可见(可用「窗口置顶」辅助)。
5. 对取不到文字的应用,是否自动回退到剪贴板且不破坏剪贴板。

**Windows**
1. Chrome / Edge / Word / 记事本 中选中文字按热键,记录走自动取词还是仅剪贴板。
2. 多显示器 + 125% / 150% 缩放下窗口位置与清晰度。
3. 回传:每款应用的取词结果(成功 / 走兜底 / 失败),以及调试日志里的取词路径。

### 清单 4 — 阶段 4
1. 干净机器上双击 dmg / exe,是否无 Gatekeeper / SmartScreen 拦截(当前未签名,预期会有提示)。
2. 触发一次自动更新(自动更新尚未实现)。
3. 回传:安装截图(避开敏感信息)、更新日志。
