# 桌面版长期任务进度

本文件是桌面版移植的**唯一进度来源**。每次新会话先读本文件与 `docs/desktop-plan.md`,再说「继续」即可接着做,不依赖对话记忆。完成一项就勾选、记下验证结果。

## 当前基线与迭代方向

截至 2026-11-21，当前桌面分支版本为 **v0.9.64**。早期路线见下方里程碑，逐版变更见 [桌面更新记录](../desktop/CHANGELOG.md)。

- **翻译工作台**启动即打开，默认粘贴即翻译。下一次粘贴替换原文并发起新查询。「直接翻译」和「引导理解」在工作台内切换。全局热键取词暂停。
- **AI 老师**从日常英文短语和句子查询中选题。每组围绕一个阅读难点，在新句里练短语含义或句子关系，结合答题和提示使用情况安排复练。
- 点击「更多」查看已安装版本和 GitHub 发布页。Windows 和 Linux 窗口在创建时显式移除 Electron 应用菜单。

| 优先级 | 方向 | 状态与验收边界 |
| --- | --- | --- |
| 当前 | Windows 安装版自动更新 | 后台下载，用户确认后重启安装。端到端升级需两版安装包在 Windows 验收 |
| 待实机试听 | **改善桌面端英文朗读**。已接入阿里云百炼北京 `qwen3-tts-flash`，默认使用 Jennifer 美式女声 | 本地模拟已验证显式启用、设置保存、音频播放和停止。用相同单词、短语和例句对比系统与百炼的发音、重音、停顿和首播等待时间 |
| 暂停 | 剪贴板格式恢复、原生取词和上下文 | 桌面端当前使用主动粘贴 |
| 后续 | 签名、公证与更新 | 安装与更新需干净机器验收 |

## 协作分工

- **我(agent)**:写代码、单测、构建脚本、验证脚本、文档;更新本文件;把大任务拆成可独立验收的小步。
- **你**:在 macOS / Windows 实机上按下方清单手动验证,回传现象、日志、截图;阶段 4 提供 Apple Developer 账号与代码签名证书。
- **安装包获取**。推送 `desktop` 分支相关代码、推送 `desktop-v*` 标签或手动触发后，在成功运行的 **Artifacts** 里下载 `selected-text-translator-macOS`（Apple Silicon arm64）或 `selected-text-translator-Windows`（x64 安装包与便携 ZIP）。标签构建通过后创建 GitHub Release。
- **凭据**:API Key、证书、账号一律走环境变量或仓库外私有配置;不要发给我,不要出现在截图、日志、测试报告、提交里(沿用 AGENTS.md 约定)。

## 环境与验证边界

- 本轮核对的本地环境:Ubuntu / Node 22.22.1 / npm 9.2.0;现有 Electron E2E 使用 Playwright 与 Xvfb,可验证模拟输入和渲染行为。
- CI 使用 GitHub 托管的 `macos-latest` 和 `windows-latest` runner 产出安装包。安装和系统交互仍需在实机验收。
- 用户无法方便提供目标平台环境,**实机交互测试全部由用户手动执行**,我按回传迭代。
- Linux 内可自动操作受控测试页面与 Electron 窗口;目标平台的系统授权弹窗、跨应用选词、原生输入法和真实音色仍由你验证。
- 真实 API 凭据仅在获准的验证中使用,从环境变量或仓库外私有配置读取,不进仓库、提交、日志或截图;临时凭据文件用完删除。

## 用户反馈(驱动 v0.8.1 起的重新设计)

> Windows 上按 `Alt+Shift+E` 没反应;"让你移植也不是让你全盘照搬,要按客户端软件的使用逻辑做对应修改或优化";希望有类似 ChatGPT 的对话框,没法选区的内容可以自己复制过来翻译。

原来的实现把浏览器扩展的「注入浮层 + DOM 选区」整套搬过来:取词失败或剪贴板为空时直接 `hide()`,用户看不到任何反馈。已按桌面软件逻辑重做,见下方里程碑与 v0.8.1–v0.8.10 变更记录。

## 手动实机验证清单(由你执行)

回传时请附:平台 + 系统版本 + 代码版本(commit)、操作步骤、预期 vs 实际、日志、截图。截图注意避开 API Key 输入框。

### 清单 1 — 主交互

1. 安装对应平台的版本并启动，打开「更多」核对安装版本。Windows 主窗口和辅助窗口不显示默认英文菜单，按 `Alt` 也不会唤出。
2. 首次使用时配置 API 地址、密钥和模型。聚焦原文框，连续粘贴两段不同的文字，每次应只提交一次并替换上次原文。测试「粘贴并翻译」按钮和手动提交。
3. 切换「直接翻译 / 引导理解」。确认结果随模式变化，历史仍可回看。使用中文输入法确认候选，确认尚在组词时不会误提交。
4. 查一个英文短语和一个英文句子。打开 AI 老师，在练习页核对素材来源，做题并使用提示，确认完成后保存结果并安排复练。中途切到工作台再回来，应继续原来的题。
5. 检查关闭窗口后可用托盘或再次启动恢复窗口，已安装版本仍可查看。

### 清单 2 — 功能与数据
1. 朗读原文/停止;试听音色、语速。
2. 收藏一条 → 打开表达本 → 退出并重启 App → 数据仍在 → 导出 JSON → 清空后导入 → 条数与复习进度一致。
3. 重启 App 后最近 20 条学习记录仍在,历史侧栏可搜索并切换显示;新翻译后的原文仍留在顶部输入框,可就地编辑。
4. 设置项、主题、字号、窗口位置尺寸、置顶、开机自启重启后保持。
5. 系统加密可用时,API Key 在 `userData/sync.json` 中应为 `enc:v1:` 开头的密文。当前加密探针失败会跳过加密,需如实记录测试平台的实际状态;不要把含密钥的文件或截图回传。
6. 回传:音色列表是否为空、有无 TTS 报错、数据是否持久。

### 清单 3 — 原生取词阶段保留，当前暂停
**macOS**
1. 首次启动是否弹出辅助功能授权;授权后重启 App。
2. 分别在 Safari、Word、VS Code、预览(PDF)中选中文字并按热键,确认是否取到(不依赖剪贴板)。
3. 卡片是否贴着选区位置(rect)。
4. 全屏应用、多 Spaces / 外接显示器下窗口是否可见(可用「窗口置顶」辅助)。
5. 对取不到文字的应用,是否自动回退到剪贴板且不破坏剪贴板。

**Windows**
1. Chrome / Edge / Word / 记事本 中选中文字按热键,记录走自动取词还是仅剪贴板。
2. 多显示器 + 125% / 150% 缩放下窗口位置与清晰度。
3. 回传:每款应用的取词结果(成功 / 走兜底 / 失败),以及调试日志里的取词路径。

### 清单 4 — 阶段 4
1. 干净机器上双击 dmg / exe,是否无 Gatekeeper / SmartScreen 拦截(当前未签名,预期会有提示)。
2. Windows 先用 v0.9.63 的 `.exe` 覆盖安装一次。下一版发布后，打开旧版，等后台下载完成或在「更多」中手动检查。
3. 点「重启并更新」，确认程序重新打开后版本号已升级，原有模型配置、翻译历史和表达本仍可用。回传系统版本和更新日志，避免包含凭据。
