# 桌面端更新记录

## 0.9.62 · 2026-11-21

- 翻译工作台默认粘贴即提交。连续粘贴会开启新查询，手动输入可以点「翻译」。暂停桌面全局热键取词，直接启动应用即可打开工作台。
- 「直接翻译」和「引导理解」在工作台内切换。独立的「AI 老师」使用日常查过的英文句子和短语出题，提供提示、讲解和新句复练。
- 「更多」显示当前安装的版本号，可用系统浏览器打开发布页。Windows 和 Linux 窗口创建时显式移除 Electron 默认菜单。
- 英文朗读可以启用阿里云百炼语音。设置支持试听、复用百炼北京翻译密钥或填独立密钥，云服务不可用时使用系统语音。
- 修复中文、日文等输入法组合期间误触发翻译的问题：拼音或候选文字尚未确认时暂停自动翻译，确认后再按原有间隔翻译最终文本，组合开始时取消之前排队的自动请求。
- 开启「Enter 发送」后，确认输入法候选词不再误提交；组合中的 Esc 留给输入法处理，避免窗口意外隐藏。普通 Enter、Ctrl/⌘+Enter 和手动翻译继续可用。
- 修复结果「更多」菜单被顶部输入区裁剪、导致「重新生成」等操作点不到的问题：改为原生顶层浮层，靠近窗口边缘时自动换向；不支持锚点定位时用坐标回退。

此版本来自工作台分支。从 0.9.61 切换后，请在设置里重新确认学习模型。0.9.61 的练习记录保留在原 `teacher.json`，可在 0.9.61 中查看。系统加密探针失败时，API Key 会以明文保存在本机配置中。

## 0.9.61 · 2026-11-19

- 新增独立的「AI 老师」模式。阅读练习可参考本机近期查过的词条，根据回答和查看提示的情况调整下一题。
- 恢复「引导阅读」。输入单词、短语或句子后可以逐条看提示，再主动展开解析。
- 桌面界面采用 Material 3 风格，随系统切换浅色和深色。翻译页新增清空、字符上限提示，以及通过停止按钮或 `Esc` 取消翻译。

## 0.9.60 · 2026-11-19

- `Selected Text Translator` 安装包默认启动单窗口翻译界面。沿用原版应用标识和本地数据目录，原版模型配置可继续使用。
- 粘贴或输入后手动提交，原文保留在编辑区，译文可直接复制。关闭窗口即退出。历史和收藏继续保存在本机，可用旧版访问。

## 0.9.59 · 2026-11-19

- 新增 macOS 单窗口翻译预览，发布为独立的 `Selected Text Translator Preview` 安装包。打开后直接粘贴或输入，点击「翻译」或按 `⌘ Enter`，在右侧查看并复制译文。窄窗口上下排列。
- 复用现有翻译服务，支持手动语言方向、流式结果和失败重试。模型配置单独保存，预览可以与原版同时安装。

## 0.9.58 · 2026-11-18

- 修复空译文的误导性状态:模型返回空译文时不再显示「完成」并卡在「等待译文…」,而是明确报错「模型没有返回译文,请重试或换个模型」,原文回填输入框、可直接重试。verify 守卫 + Electron E2E 覆盖。
- 空译文(及空引导)不再写入翻译记忆,避免把错误结果缓存下来污染后续查询。

## 0.9.57 · 2026-11-18

- 修复默认翻译模型下词典式学习卡不出现的问题:此前 qwen-mt 流式路径把词条详情写死为空,而词典卡是差异化核心。现在单个英文单词用 qwen-mt 模型翻译时,自动改走已配置的学习模型结构化路径,在**同一次请求**里拿到译文+音标+释义+语境,不额外增加 API 调用。短语/句子仍走快速路径,未配置学习模型时行为不变。共享模块,已验证 Chrome 扩展无回归。

## 0.9.56 · 2026-11-18

- 原文留在输入框就地编辑:翻译后不再清空输入框、不再把原文另放到下方卡片;想清空用「清空输入」。结果卡只呈现译文/解析,恢复完整卡片边框。
- 删除引导卡顶部的空洞标语「先想一想,再看提示,最后揭晓答案 · 主动思考记得更牢」——提示阶梯与「揭晓答案」按钮本身已足够清楚。更干净的单一结果视图。verify 守卫 + Electron E2E 覆盖。

## 0.9.55 · 2026-11-17

- 新增「术语表」:可为固定术语指定译法(如 Apple→苹果公司、May→五月),翻译时自动作为术语规则下发给模型,保证前后用词一致——这是专业翻译工具的核心能力。通用模型把规则追加到系统提示词,通义千问 MT 模型把规则前置到用户内容。
- 术语表在设置面板中增删,持久化到本地配置;术语变更会同步影响翻译记忆的缓存键,避免返回旧译法。verify 守卫 + 单元测试 + Electron E2E 覆盖术语下发。

## 0.9.54 · 2026-11-17

- 修复翻译记忆的大小写碰撞:此前缓存键会把原文转小写,导致大小写不同但含义不同的词(如 May/may、Turkey/turkey、Apple/apple)命中同一条缓存、返回错误译文。现在缓存键保留原文大小写(仍折叠多余空白、模型名仍忽略大小写),不同大小写分别翻译与缓存。E2E 覆盖大小写不同的两段文本各自走 API、不互相命中记忆。

## 0.9.53 · 2026-11-17

- 翻译请求遇到 429(请求过于频繁)时自动做有界重试:优先遵循服务端 Retry-After,否则指数退避,最多重试 2 次;重试等待可被用户取消或超时中断,不会拖延取消响应。5xx / 401 等行为保持不变。
- 新增纯函数重试策略模块与单元测试、后台运行时测试(429 后成功 / 重试上限后报错),Chrome 扩展与桌面端共享同一逻辑。verify 守卫覆盖。

## 0.9.52 · 2026-11-17

- 修复「重新生成 / 深入引导理解」发起新请求时未取消其他进行中请求的问题:此前后台按窗口中止旧请求且不派发事件,导致旧卡片一直转圈、无错误提示。现在这两个入口与普通提交一样先取消其他进行中的翻译,并把它们标记为「已被新的翻译取代」。verify 守卫 + Electron E2E 覆盖。

## 0.9.51 · 2026-11-17

- 翻译完成后,译文(或引导模式的答案要义)会通过独立的礼貌级实时区域播报给屏幕阅读器用户,而不只是状态栏的「完成 · N ms」。此前视障用户听不到实际译文内容。
- 播报做了轻微延迟与去重,避免与输入/焦点相关的语音冲突;实时区域以视觉隐藏方式呈现,不影响现有布局。verify 守卫 + Electron E2E 覆盖译文播报。

## 0.9.50 · 2026-11-17

- 修复翻译记忆的键未包含「原文语言」的问题:此前同一段文字在固定不同原文语言(如 English vs Japanese)时会命中同一条缓存,可能返回错误译文。现在缓存键纳入原文语言(默认 auto,向后兼容),桌面端与 Chrome 扩展同步修复。
- 增加单元测试、verify 守卫,确保记忆键区分原文语言。

## 0.9.48 · 2026-11-17
