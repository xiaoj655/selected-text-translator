# 桌面端更新记录

## 0.8.25 · 2026-11-16

- 引入 Material 3 动效系统：标准缓动、强调进入 / 退出缓动，以及 50ms–500ms 的十级时长阶梯
- 将旧版 `--t` 重新指向 M3 时长与标准缓动，全站既有的过渡无需改动即统一升级
- 对话框、抽屉、侧栏、遮罩采用强调减速曲线与 300ms 时长，进出更从容
- 卡片、输入框、按钮、气泡等表面统一 200ms 标准缓动，状态层压到 100ms 更跟手
- 悬浮卡与主窗口共用同一套缓动与时长，交互节奏一致
- 保留「减少动效」通配符规则，偏好开启时所有新动效自动降为近零时长

## 0.8.24 · 2026-11-16

- 卡片改为 M3 悬浮卡片：surface-container-low 底色、outline-variant 描边、rest/hover 两级高度阴影，层级更清晰
- 输入区改为 M3 外框文本域：聚焦时 1px 主色描边 + 主色聚焦环，取代原先的柔和光晕，输入状态更明确
- 设置抽屉输入框与历史侧栏搜索框统一采用同一套外框文本域令牌，焦点反馈全应用一致
- FAB（回到最新）使用 primary-container 容器色与 level3 高度，悬停升到 level4，交互反馈更贴 Material
- 标签与状态标识改为 M3 chip：选中 chip 用 secondary-container，辅助 chip 用描边透明底，形状与间距统一
- 全部旧版变量保留别名，卡片高亮、结果标签圆点、词义词条等既有视觉不受影响

## 0.8.23 · 2026-11-16

- 为所有按钮引入 M3 状态层：悬停 / 聚焦 / 按压统一由 currentColor 透明度驱动，不再靠生硬的整块变色传达交互
- 定义 M3 按钮角色令牌（filled / tonal / outlined / text / icon / FAB），主窗与悬浮卡共用同一套语义
- 主操作、操作区、引导与设置按钮统一为胶囊形状；分段控件选中态改用 secondary-container，悬浮按钮改用 primary-container + elevation 3
- 保留危险操作、复制成功、收藏等既有语义色，并显式排除强调色色块，确保选中勾 ✓ 不被状态层遮盖
- 悬浮卡按钮同步补齐状态层与形状，两个窗口的按压反馈完全一致
- 补齐禁用态：disabled 按钮不显示状态层，交互反馈更克制

## 0.8.22 · 2026-11-16

- 建立 M3 排版比例：display / headline / title / body / label 全套字号、行高、字重、字距令牌，全部由单一字号基准派生
- 字号偏好从「只放大正文」升级为全局生效：切换小 / 大字号时，译文、标题、标签、按钮、菜单文字一并协调缩放
- 引入 M3 形状角色 corner-small / medium / large / extra-large / full，统一卡片、输入框、菜单、弹层的圆角层级
- 引入 M3 高度层级 level0–3，卡片悬停时由 level1 平滑升至 level2，弹层与悬浮卡分别使用对应高度
- 悬浮卡与主窗共用同一套排版 / 形状 / 高度令牌，浅深色与五种强调色下表现一致
- 保留旧版 `--font` / `--result-font` 变量作为兼容别名，既有样式与字号设置无需改动

## 0.8.21 · 2026-11-16

- 引入 Material 3 色彩体系：参考色阶 → 系统角色 → 组件语义的分层令牌，替代散落的硬编码颜色
- 为五种强调色各建立完整 tonal palette（primary / secondary / tertiary / error / success 及容器色），深浅两套角色自动派生
- 使用 `light-dark()` 与按主题设置的 `color-scheme`，让系统角色随浅色 / 深色 / 跟随系统实时切换，无需重复维护两套调色板
- 保留全部旧版变量作为别名，界面、悬浮卡与既有交互无需改动即可平滑过渡
- 补充 `<meta name="color-scheme">`、M3 选中色、`accent-color`、`prefers-contrast: more` 与 `forced-colors` 系统色回退，避免未着色闪烁并提升可读性
- 新增 M3 状态层透明度、形状与高度令牌，为后续组件与交互改造打底

## 0.8.20 · 2026-11-16

- 流式输出改为就地更新译文文本，不再每个数据块重建整张结果卡片。
- 打字光标随分块同步保留，朗读/取消/收藏等操作按钮不再闪烁重排。
- 流式期间保持卡片内的键盘焦点与阅读位置，输入和滚动都不被打断。
- 仅在请求开始、完成、失败等状态切换时重建卡片，减少无谓 DOM 操作。
- 兼容词典解析与结果状态标签，完成态的内容与排版和原先完全一致。

## 0.8.19 · 2026-11-16

- 新增「导出对话」下拉菜单:顶栏一键展开,提供 Markdown 下载、JSON 下载与复制为 Markdown 三种方式。
- Markdown 导出包含原文、译文、音标、词典释义与例句、语境分析,以及引导理解的逐步提示与揭晓答案,适合直接归档到笔记。
- JSON 导出为结构化数据(含模式、状态、词典与引导字段),方便二次处理或备份。
- 复制为 Markdown 直接写入系统剪贴板;导出文件名自动带上日期,空对话时给出明确提示。
- 重做结果排版:每条结果增加「译文 / 引导解析 / 正在处理 / 出错了」状态标签、更舒展的正文字号与行高,操作区用虚线分隔,层级更清晰。
- 底部状态栏新增统计行「共 N 条 · 翻译 X · 引导 Y · 原文 M 字」,新建 / 重新生成 / 删除后实时更新。
- 支持 `Ctrl(⌘)+E` 打开或关闭导出菜单,点击空白处或按 `Esc` 收起,并已写入快捷键帮助面板。

## 0.8.18 · 2026-11-16

- 新增可选强调色主题:设置 → 外观提供 5 种配色(靛蓝 / 海蓝 / 翠绿 / 玫红 / 琥珀),点击色块即时切换。
- 强调色会统一驱动品牌标识、渐变按钮、标签、选中态、聚焦光环与高亮描边,整体观感一致。
- 浅色与深色模式都针对每种强调色生成协调的浅色底与文字色,不会出现对比度不足。
- 设置会随偏好持久化,悬浮卡片通过存储变更广播同步换色,无需重启。
- 切换后底部状态栏给出「已切换强调色」反馈,当前色块显示勾选标记。

## 0.8.17 · 2026-11-16

- 新增历史侧栏:点左上角按钮或按 `Ctrl(⌘)+H` 打开,按时间倒序列出全部对话记录。
- 侧栏支持实时搜索:输入关键词即时过滤原文、译文与记录类型,并显示「共 N 条 · 匹配 M 条」。
- 点击任意历史条目即可跳转到对话中对应位置,自动展开被折叠的卡片并短暂高亮定位。
- 每条记录展示模式标签、时间、原文与结果摘要,长文本自动省略,便于快速浏览。
- 侧栏支持点击遮罩、关闭按钮或 `Esc` 收起,并已加入快捷键帮助面板。
- 新建翻译、重新生成、清空对话后侧栏内容会自动同步刷新。

## 0.8.16 · 2026-11-16

- 新增键盘快捷键帮助面板:点右上角 `?` 或按 `?` / `Ctrl(⌘)+/` 打开,列出发送、聚焦、帮助、折叠等操作,并显示当前全局取词热键。
- 新增 `Ctrl(⌘)+K` 一键聚焦并选中输入框,长会话中也能立刻开始输入。
- 复制结果 / 复制原文后按钮就地变为「✓ 已复制」,主窗口与悬浮卡片都有即时反馈,不再只靠底部状态栏。
- 翻译卡片可折叠:点击卡片标题栏即可收起 / 展开结果,方便快速浏览历史。
- 新增「回到最新」悬浮按钮:向上滚动后自动出现,点击平滑滚回底部。
- 输入内容过长(超过 6000 字)时字数统计变红并提示可能影响响应。
- 设置 / 帮助面板支持点击遮罩或 `Esc` 关闭。

## 0.8.15 · 2026-11-16

- 全新配色与设计系统:改用靛蓝 / 紫罗兰渐变主色 + 中性冷灰层次,新增共享 `tokens.css` 设计令牌,主窗口与悬浮卡片统一视觉语言,并完整支持浅色 / 深色 / 跟随系统。
- 重构主窗口:渐变品牌标识、内联 SVG 图标、分段式模式切换、带阴影与圆角的层级卡片,操作按钮改为描边幽灵样式,信息层级更清晰。
- 设置面板分组重排(模型连接 / 通用 / 外观 / 快捷键),输入框聚焦态、分区标题与诊断信息重新设计。
- 悬浮卡片重做:渐变标签、图标化控制按钮、释义面板与结果排版优化。
- 空状态新增引导插画与示例快捷键提示;引导理解的「再提示一点 / 揭晓答案」并入统一操作区。
- 修复隐藏的提示条因 `display:flex` 覆盖 `[hidden]` 而始终显示空白栏的问题。

## 0.8.14 · 2026-11-16

- 修复 Windows 构建机上标签校验失败:校验脚本显式使用 bash。
