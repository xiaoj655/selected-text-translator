# 桌面端更新记录

## 0.8.15 · 2026-11-16

- 全新配色与设计系统:改用靛蓝 / 紫罗兰渐变主色 + 中性冷灰层次,新增共享 `tokens.css` 设计令牌,主窗口与悬浮卡片统一视觉语言,并完整支持浅色 / 深色 / 跟随系统。
- 重构主窗口:渐变品牌标识、内联 SVG 图标、分段式模式切换、带阴影与圆角的层级卡片,操作按钮改为描边幽灵样式,信息层级更清晰。
- 设置面板分组重排(模型连接 / 通用 / 外观 / 快捷键),输入框聚焦态、分区标题与诊断信息重新设计。
- 悬浮卡片重做:渐变标签、图标化控制按钮、释义面板与结果排版优化。
- 空状态新增引导插画与示例快捷键提示;引导理解的「再提示一点 / 揭晓答案」并入统一操作区。
- 修复隐藏的提示条因 `display:flex` 覆盖 `[hidden]` 而始终显示空白栏的问题。

## 0.8.14 · 2026-11-16

- 悬浮卡片可拖动:拖标题栏即可移动位置,不再固定在弹出点挡住原文。
- 悬浮卡片可固定:点「钉」后切换其他窗口不再自动关闭,方便对照原文慢慢看;按 `Esc` 或 × 仍可关闭;下次取词自动取消固定。
- 修复 Windows 构建机上标签校验失败:校验脚本显式使用 bash。

## 0.8.13 · 2026-11-16

- 新增桌面端发布流水线:推送 `desktop-v*` 标签即自动构建 Windows / macOS(x64 + arm64)/ Linux 安装包,校验标签与 `desktop/package.json` 版本一致后,以本文件对应版本的说明创建 GitHub Release,并附 SHA256 校验和。
- 新增 Linux(AppImage)构建,Windows / macOS / Linux 三平台安装包随每个版本一起发布。

## 0.8.12 · 2026-11-16

- 修复 `Esc` 无法关闭悬浮卡片:卡片为不抢焦点设计,页面内按键监听收不到 `Esc`,改为卡片可见期间注册全局 `Escape` 快捷键,关闭即注销。
- 卡片高度随内容自适应(120–520px),短结果不再留大片空白。
- 卡片跟随主窗口的主题、字号、减少动效设置;热键触发时即时下发,运行中修改实时同步。
- 错误消息全面中文化:未配置服务、请求超时、流式解析失败等提示不再出现英文。
- 主窗口记录时间改为 24 小时制。

## 0.8.11 · 2026-11-16

- 修复热键翻译显示 `[object Promise]`:Electron 45 的 `clipboard.readText()` 返回 Promise,取词链路全部改为 await。
- 修复无 keyring 的 Linux 上保存设置失败:safeStorage 加密改为探针验证,不可用时降级为明文存储。
- 新增悬浮翻译卡片:热键取到文字时在鼠标附近弹出置顶小窗,流式显示译文;可复制结果/原文、朗读、重新生成、收藏、转入主窗口;完成后自动同步进主窗口历史。

## 0.8.10 · 2026-11-15

- 空状态提供可直接点击的示例文本,首次使用有引导。
- 启动即预加载主窗口,热键响应更快。
