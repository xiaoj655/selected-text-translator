# 桌面端更新记录

## 0.9.3 · 2026-11-17

- 热键取词失败时给出分平台的可操作提示:macOS 提示去「系统设置 → 隐私与安全性 → 辅助功能」授权,Windows 提示先选中文字再按热键、或切到「仅用剪贴板取词」,不再只有一句笼统的「没有取到文字」。
- 提示文案统一以「查看设置」按钮收口,用户可一键直达设置排查,呼应最初「热键取词基本不可用」的反馈。

## 0.9.2 · 2026-11-17

- 新增 Anki 记忆卡导出:导出菜单里新增「Anki 记忆卡 (.txt)」,把每条完成的对话以 `原文⇥译文` 的 TSV 文本导出,可直接导入 Anki 制作记忆卡。
- 导出内容做 TSV 安全处理:单元格内的制表符、换行与多余空白会折叠成空格,避免破坏 Anki 的字段/行列结构。
- 只导出有原文与译文的完成记录,空结果有明确状态提示;与现有 Markdown / JSON / 复制导出并列。

## 0.9.1 · 2026-11-17

- 交互收敛:主窗口与悬浮卡的每条结果只保留一个高 emphasis 的「复制结果」,其余动作(复制原文、复制双语对照、回填、收藏、朗读译文、单条导出 Markdown、删除)收进 `⋯` 溢出菜单,告别一排 7–8 个同质按钮。
- 新增「朗读译文」:既能朗读原文,也能朗读译文,方便语言学习;溢出菜单里按结果是否存在动态显示。
- 新增「复制双语对照」:一键得到「原文 / 译文」并列文本,便于分享与归档。
- 新增单条「导出此条为 Markdown」:`buildMarkdown` 抽出 `entryToMarkdown`,整段导出与单条导出共用同一套格式。
- 新增「朗读语速」设置(0.5×–1.5×),写入 `speech_rate`,朗读引擎实时读取。
- 修复 Esc:当前有菜单/面板(溢出菜单、更多菜单、设置、帮助、导出、历史)时,优先关闭最上层,不再直接关掉整个窗口。
- 修复溢出菜单被裁剪:卡片自动高度测量菜单底部、主窗口底部条目菜单向上翻转、卡片圆角与菜单层级修正。
- 视觉微调:对话区居中 820px、原文气泡改为低强调样式、实线分隔替代虚线、滚动按钮与 Snackbar 上移避免遮挡输入区、历史图标换成时钟。
- 取词更稳:剪贴板轮询从 8×40ms 提升到 15×50ms,慢机器上取词成功率更高。

## 0.9.0 · 2026-11-17

- 交互与视觉整体重做:采用原生克制的单一强调色 + 中性表面体系,替换原先厚重的 Material 3 层层着色,窗口更轻、阅读更专注。
- 悬浮卡改为稳定驻留:只在 Esc、点关闭、或下次取词时收起,不再因为切窗口/失焦就消失,取词结果可以放心停留、复制、朗读。
- 主窗口顶栏收敛为导出/设置/更多三个动作,表达本、清空、日志、快捷键归入「更多」菜单,减少视觉噪音。
- 修复帮助按钮标签缺少闭合 `>` 导致的顶栏渲染畸形问题。
- 翻译协议、历史、设置、TTS、取词引擎等底座完全保留,仅重构呈现层;全部功能与键盘可达性保留。

## 0.8.39 · 2026-11-16

- 底部状态栏补齐 role=status / aria-live=polite / aria-atomic=true,让复制、删除、撤销、保存、回填等临时反馈都能被读屏完整播报,不再"看得见却听不到"。
- 与已有的 Snackbar、设置状态、悬浮卡结果统一为同一套无障碍状态播报,反馈语义全应用一致。
- 主窗口、悬浮卡以及代码里动态生成的所有纯装饰内联 SVG 统一加 aria-hidden=true,避免读屏把无意义图形重复朗读。
- 按钮可读名称仍由 aria-label 提供(v0.8.37),隐藏图形后语义不丢失、键盘可达性不变。
- 不新增任何功能,只做最终可访问性与语义收口,呼应"功能不在于多,而在于精"。
- 全套回归:5 种强调色(靛蓝/海蓝/翠绿/玫红/琥珀)× 明暗主题共 10 组渲染,0 页面报错;桌面 verify、229 项单测、浏览器主流程全部通过。
