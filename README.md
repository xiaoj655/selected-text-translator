# Selected Text Translator

一个轻量的 Chrome 划词阅读助手：快速翻译、听原文，或通过英文线索自己理解。

## 阅读方式

选中文字后，悬停在 `Aa` 按钮上或直接点击即可打开阅读卡片。

- **翻译**：显示译文。通用模型还可以补充单词释义与用法。
- **引导理解**：结合选区所在段落，先显示一条简短英文提示。点击「再提示一点」逐层展开，最多三层。随时可以「揭晓答案」，查看英文释义、解释和例句。无需输入猜测。
- **朗读**：独立于模型请求，可读选区，也可读包含选区的原句。支持音色选择、语速调整和试听。
- **音标**：通用翻译模型返回时直接显示；使用 qwen-mt 翻译时，配置学习模型后会自动补充单词音标。

同一选区内，已生成的结果与提示进度会保留，切换模式无需重复生成。切换模式会记住选择，之后的划词沿用该模式。可用 `Alt+Shift+E` 打开当前选区（可在 Chrome 扩展快捷键设置中调整）。按 `Esc`、点击卡片外部或点右上角关闭按钮退出。拖动卡片右侧边缘可以调整宽度。

### 再次查看与重新生成

近期再次选中相同内容、相同语境和位置时，可直接复用已完成的结果。不同语境、位置、模型或服务配置会分别处理，避免同词不同义混用。

卡片右上角的 `⟳` 可以重新生成当前模式的结果，会发起新的模型请求。更新期间旧内容和朗读仍可用；成功后引导从第一条提示重新开始，主动点击才揭晓答案。失败会保留旧内容和进度，点击「重试生成」才再次请求，不会因为反复悬停自动重试。

临时结果仅使用后台内存，最多 32 项、序列化结果总量 1 MiB、最长 5 分钟；后台休眠、重载或更换模型服务配置会清空。它不会额外写入本地存储，重新生成也不会覆盖表达本中的手动修订。

## 我的表达本

在翻译结果或引导答案中点击「收藏表达」，把原文、语境、释义和例句保存到本机。打开插件弹窗中的「我的表达本」，可以搜索收藏、回到原文，并复习到期条目。

复习不需要输入：先回忆，再揭晓，选择「还不熟」或「记住了」。新词约 24 小时后开始复习；还不熟的词 10 分钟后再看，记住的按 1、3、7、14、30 天的间隔逐步安排。同一轮不会立刻重复同一张卡片。

条目保存在 `chrome.storage.local`，不上传云端、不自动跨设备同步。支持 JSON 导出与导入，恢复时合并新词，不覆盖已有同词同义条目的进度。最多 2,000 条、4 MiB 条目内容；导入文件最多 5 MiB，以兼容旧版备份中的缩进空白。卸载前请导出需要保留的内容。

表达本内可以朗读词、原句和例句，并查看收藏时保留的用法结构。复习时按空格揭晓，按 `1` 标记「还不熟」、`2` 标记「记住了」；移除条目后可以撤销，保留原有复习进度。新版备份格式为 v2，同时兼容导入 v1 备份。

### 修订学习内容

模型可能判断错义项、写出不准确的搭配或音标。展开收藏条目，点击「修订内容」，可以修改释义、用法与例句；「更多内容」中可校订解释和音标。保存不会重置复习进度，也不会修改原文及来源。

保存只提交实际改动字段，其他页面的独立修改会保留；同一字段发生冲突时，你的草稿会保留，点击「载入最新内容」后才替换草稿。草稿仅在当前页面内保留，硬刷新或关闭前请保存或复制。修订是可选功能，不影响逐层提示或复习流程。

## 安装

1. 下载或克隆本仓库：

   ```bash
   git clone https://github.com/xiaoj655/selected-text-translator.git --depth=1
   ```

2. 在 Chrome 打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择**包含 `manifest.json` 的仓库根目录**。
4. 升级已有版本时，在扩展管理页点击重新加载，并刷新要使用的网页。此版本增加了 TTS 权限。

无需构建，正常使用也不需要安装 Node.js 依赖。Chrome 内部页面及部分受限页面无法注入划词入口。

## 配置

点击工具栏上的插件图标，展开「连接模型」，填写 API 地址、API Key 和翻译模型。支持 `/chat/completions` 风格的兼容接口。也可点击「检测连接并获取模型」，在输入框中筛选服务实际提供的模型。

默认翻译配置为阿里云百炼：

- API 地址：`https://dashscope.aliyuncs.com/compatible-mode/v1`
- 翻译模型：`qwen-mt-flash`
- API Key：从自己的服务提供商获取。

**学习模型**用于英文引导与额外音标，需要填写当前 API 服务实际支持的通用模型名称，使用相同的地址和密钥。翻译本身使用通用模型时，学习模型可以留空；`qwen-mt` 系列只负责翻译，需要额外指定通用模型才能提供引导。

| 能力 | qwen-mt 翻译模型 | 通用模型 |
| --- | --- | --- |
| 译文 | 支持，flash / lite 流式输出 | 支持，JSON 输出 |
| 单词音标 | 通过学习模型补充 | 可直接返回 |
| 单词释义与用法 | 不提供 | 可直接返回 |
| 英文引导 | 通过学习模型提供 | 支持 |
| 原文朗读 | 支持，不依赖模型 | 支持，不依赖模型 |

朗读通过 Chrome TTS 调用可用音色，实际音质取决于系统或已安装的语音引擎。设置中标注「在线」的音色需要联网。模型请求可能产生所用服务的 API 费用。

引导仅发送选中的文字及附近一段有限长度的上下文给配置的 API 服务，不上传整页内容。调试日志默认关闭，不记录选区正文、模型响应正文或 API Key。

可以在弹窗中单独停用当前页面，或停用当前路径及子路径；全部设置页支持管理停用规则。

## 开发与验证

```bash
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

浏览器验证需要 Node.js 20.11+，会在临时 Chrome 配置中加载真实扩展，使用本地模拟 API，检查提示展开、答案隐藏、缓存、音标、朗读消息、键盘操作、滚动定位与设置页布局。TTS 在自动化中模拟调用，不代表已验证设备上的实际音质。预览截图默认输出至系统临时目录 `selected-browser-preview/`，可通过 `STT_ARTIFACT_DIR` 指定目录。

### 可选：真实接口验证

通过环境变量提供 `STT_API_KEY`、`STT_BASE_URL` 和 `STT_LEARNING_MODEL`，再运行 `npm run test:live` 或 `npm run test:live:browser`。也可以用 `STT_LIVE_CONFIG` 指向仓库外的私有 JSON 配置（字段为 `apiKey`、`baseUrl`）。不要把密钥写入仓库。

这两项检查会产生真实 API 请求，普通 `npm test` 和 `test:browser` 不调用付费服务。后者使用隔离的临时浏览器配置，检查真实模型的提示、揭晓与收藏链路，结束后删除测试配置。语音实际音质仍需在使用设备上试听。

### 打包

`npm run package:extension` 使用 Python 3 的标准库，将运行所需文件打包至 `dist/selected-text-translator-版本号.zip`，不包含测试、Node.js 依赖或本机配置。

### GitHub 自动出包

推送分支、向 `main` 提交 PR 或手动运行 `Verify and package extension` 流水线时，会先执行单元测试和浏览器交互检查，再生成 ZIP 安装包与 `SHA256SUMS.txt`。检查使用本地模拟 API，无需配置模型密钥。

在仓库 [Actions](https://github.com/xiaoj655/selected-text-translator/actions) 中打开成功的运行，从 Artifacts 下载 `selected-text-translator-版本号`，解压下载文件后即可取得插件 ZIP 和校验文件。再将插件 ZIP 解压，在 Chrome 中加载包含 `manifest.json` 的目录。出包产物保存 30 天，浏览器预览保存 7 天。

发布正式版本时，先更新 `manifest.json` 与 `CHANGELOG.md`，再推送对应的 `v版本号` 标签，例如 `v0.5.0`。流水线会检查标签与清单版本一致，在验证通过后自动创建 [GitHub Release](https://github.com/xiaoj655/selected-text-translator/releases)，附上 ZIP、校验文件和自动生成的发布说明。
